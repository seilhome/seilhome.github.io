강릉 우미 린 더 프리미어 홈페이지 리뉴얼 적용 안내

1. 어떤 파일을 쓰면 되나요?
- 기존 홈페이지가 정상 운영 중이면 seilhome-renewal-update.zip을 사용하세요.
- 사이트 전체 파일이 필요하면 seilhome-renewal-full.zip을 사용하세요.
- 두 압축파일을 모두 적용할 필요는 없습니다.

2. 업데이트 파일 적용
- 압축을 풉니다.
- index.html, css, js, images, fonts를 기존 GitHub 저장소의 같은 위치에 업로드합니다.
- 이번에는 index.html과 style.css 두 파일만 바꾸는 작업이 아닙니다.
- 새로 추가되는 css/renewal.css, js/renewal.js, images/interiors 폴더, fonts 폴더도 모두 올려야 합니다.
- 기존 이미지, 영상, news.html, CNAME 등 다른 파일은 삭제하지 마세요.
- 이 안내문은 홈페이지에 올리지 않아도 됩니다.
- GitHub Pages 반영 후 PC와 휴대폰에서 새로고침합니다.

3. 전체 파일 적용
- 압축 안 seilhome.github.io-main 폴더의 내용물을 저장소의 기존 같은 위치에 덮어씁니다.
- seilhome.github.io-main 폴더 자체가 저장소 안에 한 겹 더 들어가지 않도록 주의하세요.

4. 적용 후 확인
- 첫 화면에 48평형 거실 사진과 초록색 상담 버튼이 보이는지 확인합니다.
- 34평 C타입 / 48평 사진 전환, 평면도 선택, 상담창 열기를 확인합니다.
- 본인 번호로 분양가표 신청 1회를 진행해 스프레드시트 저장·담당자 알림·문자 수신을 확인합니다.
- 기존 Google Apps Script 주소, 기본 전송항목, 분양가표·주소 요청 구분값은 유지했습니다.
- 실제 서버 저장 및 문자 발송은 이 파일만으로 확정 확인할 수 없어, 제작 중에는 가상 전송으로 검증했습니다.

5. 변경 내용
- 실제 촬영 사진 10장을 34평 C타입과 48평으로 구분한 갤러리.
- 분양가표 문자 신청 / 방문예약 / 동·호수 상담 / 주소 안내를 바로 여는 상담창.
- 선택한 평형과 타입을 상담창에 자동 반영.
- 고정 하단 전화·분양가·방문예약 버튼.
- 과도한 첫 방문 팝업 및 고정 상담건수 표시 제거. 상품권 안내는 방문 유도 구역에 정리.
- 메인 HTML 약 6.2MB → 약 33KB. 사진은 웹용 WebP, 나머지 사진은 지연 로딩.
- 기존 광고 추적, 유입정보 전달 및 사이트 소유확인 코드 유지.

6. 클릭과 신청 측정
기존 GA4(G-JY8BHGY9N7), Clarity(xl435psnof)를 그대로 사용합니다.
- cta_click: 상담버튼을 누른 위치(cta_position), 문의 종류(request_kind).
- lead_form_start: 양식 입력 시작.
- lead_submit_attempt: 유효성 검사를 통과한 신청 전송 시도.
- lead_request_sent: 브라우저의 요청 전송 완료. 서버 저장/문자 전달의 확정 지표가 아닙니다.
- lead_submit_error: 전송 중 오류.
- phone_click: 전화상담 클릭.
- interior_photo_view / floor_plan_select: 관심 평형과 공간 선택.
실제 접수·방문확정 성과는 상담 기록과 함께 비교하세요. 기존 GA4의 lead_submit_success만 보고 있었다면 새 lead_request_sent 이벤트도 확인하세요.
광고 분석 이벤트에 이름이나 전화번호는 넣지 않았습니다.

7. 검증 범위
- Chromium 브라우저에서 320~1440px 12개 화면 너비, 가로 넘침 없음.
- 사진/평면 선택, 타입 자동 선택, 필수입력, 잘못된 번호 차단, 전송 실패/재시도, 이미지 확대 검증.
- 실제 고객 접수나 문자 발송을 발생시키지 않은 가상 요청 테스트입니다.
- 광고 성과 증가는 실제 운영 데이터로 확인해야 하며 보장하지 않습니다.
